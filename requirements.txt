#   mammoth 1.6.0      — read uploaded DOCX resumes

#   docx 8.5.0         — DOCX export
#
# External services requiring API keys (see config.example.json):
#   1. OpenAI     → https://platform.openai.com/api-keys        (OPENAI_KEY)
#   2. Anthropic  → https://console.anthropic.com/settings/keys (ANTHROPIC_KEY)
