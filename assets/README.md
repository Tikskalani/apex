# Assets

This folder holds visual assets referenced in the README.

## Recommended files to add

| File | Purpose | How to create |
|---|---|---|
| `demo.gif` | Hero animation in README | Record 30-60s of APEX running. Tools: [Kap](https://getkap.co/) (Mac), [ScreenToGif](https://www.screentogif.com/) (Windows), `peek` (Linux). Keep under 10MB. |
| `screenshot-market.png` | Market Intel tab | Browser screenshot at 1440x900, light compression |
| `screenshot-resume.png` | Resume X-Ray tab | Same |
| `screenshot-gap.png` | Gap Report tab | Same |
| `screenshot-export.png` | Sample exported PDF preview | Open the PDF in Preview, screenshot at native resolution |

## Already included

- `sample-export.pdf` — Real PDF generated by APEX, demonstrates the export quality

## Adding your own banner / logo

If you want a hero banner image at the top of the README, save it as `banner.png` (recommended dimensions: 2400x800px) and replace the README's title section with:

```markdown
![APEX](assets/banner.png)
```

You can generate a banner quickly with:
- [Figma](https://figma.com/) (free)
- [Canva](https://canva.com/) (free templates)
- [Remove.bg](https://remove.bg/) for transparent backgrounds
